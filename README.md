# OZGuard

Chrome-расширение для продавцов OZON: поиск конкурентов по SKU, сбор цен своих товаров и автоматическая подача жалоб на нарушения контента.

Сайт, инструкция и загрузка: [codefic.ru](https://codefic.ru)

## Возможности

- Бесплатный поиск других продавцов товара и импорт SKU из Excel.
- Бесплатная вкладка «Цены»: проверка своих карточек и магазина, цены с условиями скидок и экспорт полного или частичного результата в CSV.
- Жалобы с PRO: обычная подача и отдельный пакетный режим BETA с предпросмотром товаров и доказательств. Для первого запуска пакетного режима рекомендуем 2–3 SKU.
- Сохранение очереди и восстановление после сна или перезапуска браузера. Во время сна компьютера действия не выполняются; после пробуждения расширение сначала проверяет страницу и незавершённую отправку. Ручная и защитная паузы сохраняются.

## Статус обновления

Текущее обновление — кандидат: автоматические проверки выполнены, живой прогон новых сценариев жалоб и контролируемая ночная проверка ещё не завершены.

Сбор конкурентов зависит от доступных данных Ozon. Отсутствие блока других продавцов не доказывает, что на площадке нет похожих карточек или копий.

## Установка

1. Скачайте актуальную версию: [codefic.ru/#install](https://codefic.ru/#install)
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку.

Поддержка: [t.me/firadex](https://t.me/firadex)
