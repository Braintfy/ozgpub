# OZGuard

Chrome-расширение для продавцов OZON: поиск конкурентов по SKU, сбор цен своих товаров и автоматическая подача жалоб на нарушения контента.

Сайт, инструкция и загрузка: [codefic.ru](https://codefic.ru)

## Возможности

- Бесплатный поиск других продавцов товара и импорт SKU из Excel.
- Бесплатная вкладка «Цены»: проверка своих карточек и магазина, история сборов, цены с условиями скидок и экспорт полного или частичного результата в CSV.
- Рекомендации цен BETA: расчёт по обычной цене или введённым ориентирам, минимальная цена и предел изменения, CSV. Цены в кабинете не меняются.
- Жалобы с PRO: обычная подача и отдельный пакетный режим BETA с предпросмотром товаров и доказательств. Для первого запуска пакетного режима рекомендуем 2–3 SKU.
- «Повторить последний файл один раз»: необязательная настройка для жалоб на контент. После нового запроса Ozon и исчерпания других файлов бот может один раз повторить последний доставленный файл в том же обращении. По умолчанию выключена; передача оператору зависит от Ozon.
- «Нужны доказательства»: явный выбор новых файлов и дополнение прежнего обращения после основной очереди. Уже доставленные файлы распознаются по содержимому; неизвестная отправка требует сверки. Обычный запуск пропускает отложенные SKU и обрабатывает остальные, сохраняя прежние обращения.
- «Сбросить ошибки / начать заново» во вкладке жалоб: сохраните обработанные товары либо выберите повторный запуск. Старый сценарий сначала останавливается; неизвестная отправка требует сверки. Для сохранённого дополнения есть отдельные действия «Считать обработанным» и «Разрешить новый запуск».
- Сохранение очереди и восстановление после сна или перезапуска браузера. Во время сна компьютера действия не выполняются; после пробуждения расширение сначала проверяет страницу и незавершённую отправку. Ручная и защитная паузы сохраняются.
- «Помощь»: инструкция с поиском, подсказки и восемь коротких обзоров без интернета. Обзор не меняет настройки и не запускает отправку.

## Статус обновления

Добавлена галочка однократного повтора последнего доказательства для жалоб на контент. Её нужно включить перед запуском; текущая очередь сохраняет прежние настройки. Бот сначала использует остальные разные файлы, а неизвестную доставку сверяет без повторной отправки. Сохранено исправление запуска остальных SKU при отложенных обращениях. После обычной установки перезагрузите расширение и страницы Ozon, когда бот остановлен, и проверьте 2–3 SKU.

24 сентября владелец подтвердил успешный живой прогон предыдущей сборки. Новые исправления требуют отдельной живой проверки; длительный системный сон отдельно не подтверждён.

Если прежняя версия уже стоит на неизвестной отправке, а файл появился в чате, сначала обновите только расширение, сохранив исходную страницу обращения. Дождитесь сверки или нажмите «Продолжить». До сверки не сбрасывайте очередь и не создавайте её заново: отправленный файл нельзя считать недоставленным.

Сбор конкурентов зависит от доступных данных Ozon. Отсутствие блока других продавцов не доказывает, что на площадке нет похожих карточек или копий.

## Установка

1. Скачайте актуальную версию: [codefic.ru/#install](https://codefic.ru/#install)
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку.

Поддержка: [t.me/firadex](https://t.me/firadex)
